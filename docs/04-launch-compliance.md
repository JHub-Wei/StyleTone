## 1. 上线原则

1. **中国首发，单点打透**：不全球同步；先跑通中国年轻女性人像场景。
2. **纯游客、纯本地**：无账号、无登录、无照片/参数上传；MVP 合规最轻。
3. **仅月付**：¥29.9/月，不做年付/买断，降低付费墙复杂度。
4. **合规先行**：App 备案、隐私政策、订阅条款是 W1 启动项。
5. **自然与伦理**：默认自然、形变可控、不做美白/颜值评分；18+ 定位。
6. **可回滚**：形变/肤色问题可发版修复；分阶段发布；客服/热修就绪。

## 2. 首发路径

| 阶段 | 时间 | 市场 | 目标 |
|---|---|---|---|
| 内测 | W17–W20 | TestFlight 中国区 | 100 人、2 周、稳定性/自然度 |
| 首发 | W24 | 中国大陆 App Store | 冷启动、口碑、月订阅验证 |
| 扩量 | T+30–90 | 中国大陆 | 小红书/抖音投放、留存/付费优化 |
| v2.1 | 上线后 8–12 周 | 中国大陆 | 账号/登录 + 云端擦除 |
| v2.2 | 更后 | 中国大陆/全球 | 批量、多风格、细节精修、全球版 |
| 全球版 | T+90 后评估 | 英语区/新马 | 独立构建：Apple + 邮箱，无微信 |

**为什么全球后置**：目标用户、获客渠道、合规体系都在中国；全球版需要另一套语言/支付/隐私，不应在 MVP 同时做。

## 3. 上线前置条件

### 3.1 产品与质量

- [ ] P0 全通；无 P0/P1 缺陷。
- [ ] 外部盲测 ≥65%；背景扭曲 <5%；肤色无事故。
- [ ] 崩溃自由 ≥99.5%；导出失败 <1%。
- [ ] 5 组学习 ≤90s；预览 ≥30fps；12MP 导出 ≤6s。
- [ ] 月付购买/恢复/退款/离线路径全通。
- [ ] 100 名外部 Beta、2 周；Top 5 问题关闭。

### 3.2 中国合规

- [ ] App 备案完成（工信部/省级通信管理局；App Store 中国区需要）。
- [ ] 网站/落地页 ICP 备案（如自建站点）；经营资质按法律意见。
- [ ] 隐私政策/服务条款/订阅条款上线。
- [ ] PIPL 数据映射：照片/参数本地，购买/诊断最小化。
- [ ] 境内分析/崩溃服务（可选）已做隐私评估；无境外 SDK。
- [ ] 软件著作权/主体资质（如备案/审核要求）。
- [ ] 18+ 定位/年龄提示/未成年人保护按法律意见。
- [ ] 演示素材/字体/音乐/肖像授权完整。
- [ ] 无账号/无微信/无短信，因此不需要账号注销/4.8 登录。

### 3.3 运营

- [ ] 客服邮箱/企微/小红书账号；FAQ。
- [ ] 监控看板/告警/值班；境内分析/崩溃服务（如启用）。
- [ ] 发布/回滚 Runbook 演练。
- [ ] 小红书/抖音种子内容 20 条；30 位种子用户。
- [ ] 价格/付费墙/恢复购买话术。

## 4. App Store 中国区清单

| 项目 | 要求 |
|---|---|
| App 备案号 | 按 App Store Connect 要求填写；未备案不上架 |
| 类别 | 摄影与录像 |
| 年龄分级 | 按最新问卷；产品定位 18+，不做未成年人营销 |
| 价格 | 免费下载 + 月订阅 |
| 内购 | 仅月付 ¥29.9（或最近可用价）；订阅组单一商品 |
| 登录 | **无登录**；审核员可直接完成全部流程 |
| 隐私政策 | 中文；数据清单、SDK、保留期限、联系方式 |
| 服务条款 | EULA/用户协议；订阅、退款、禁止内容 |
| 支持 URL | 可访问的 FAQ + 客服 |
| 审核说明 | 无登录；示范素材路径；照片本地；无账号 |
| 出口合规 | 标准 HTTPS/TLS 评估 `ITSAppUsesNonExemptEncryption` |
| 内容版权 | 演示样片/字体/音乐授权 |
| 隐私标签 | 照片不收集；购买/诊断/使用数据如实申报 |

### 4.1 订阅与付费墙

- 仅月付 ¥29.9/月；若 App Store 无此价格点，映射最近可用价（如 ¥30），并在商店描述中展示实际价。
- 前 3 张免费；第 4 张前展示；保存/分享均计数。
- 必须展示价格、周期、自动续订、取消方式、恢复购买、隐私政策、服务条款。
- 不做虚假倒计时/隐藏关闭；不预勾选。
- 无账号：恢复购买依赖 Apple ID；删除 App 不取消订阅，帮助页说明。
- 年付/买断后置，先验证月付留存/退款。

### 4.2 审核说明模板

```text
本 App 无需登录，打开即可体验核心功能。
1. 选择“用示范照片体验” → 选内置人像 → 调整瘦脸/磨皮 → 导出。
2. 或在相册选择一张人像（PHPicker）；照片仅在本机处理，不上传。
3. 订阅：第 4 次导出前出现；仅月付；支持恢复购买。
4. 无账号、无社交、无公开内容。
5. 隐私政策/支持：<URL>。
```

### 4.3 常见拒审风险

| 风险 | 触发 | 准备 |
|---|---|---|
| 4.2 最低功能 | 功能薄/像 demo | 完整校准—编辑—导出闭环 |
| 3.1.1/3.1.2 内购 | 第三方支付/条款不全 | 只用 IAP；完整订阅条款/恢复 |
| 5.1.1 隐私 | 权限文案不清/强制相册 | PHPicker + add-only；文案具体 |
| 2.3 元数据 | “完美变美/保证瘦”夸大 | 文案准确；不承诺效果 |
| 1.2 内容 | 未来擦除/公开内容 | MVP 无社区；擦除前建审核/举报 |
| 2.1 崩溃 | 审核员遇到崩溃 | 干净设备全流程；示范路径 |

| 事项 | 适用性 | 动作 | 负责 | 门禁 |

| 照片/人脸 | 本地处理 | 不上传；不建人脸模板；权限文案准确 | 技术/法务 | W18 前 |
| 购买数据 | Apple IAP | 隐私政策披露；不接境外订阅 SDK | 产品/法务 | W20 前 |
| 诊断/分析 | 可选 | 境内服务；事件白名单；可关闭；无照片 | 技术/法务 | W20 前 |
| 未成年人 | 18+ 定位 | 不做定向营销；年龄提示/隐私政策；法律意见 | 产品/法务 | W20 前 |
| 内容安全 | 无人像社区/无云端 | MVP 无需公开内容审核；擦除 P1 另建 | 产品/法务 | P1 前 |
| 生成式 AI | P1 云擦除 | 评估备案/标识/安全评估 | 法务/技术 | P1 前 |
| 广告/营销 | 小红书/抖音 | 不虚假宣传“变美/保证效果”；素材授权 | 运营/法务 | 上线前 |
| 支付/税务 | IAP | Apple 结算；境内主体税务 | 财务 | 上线前 |

## 6. 数据清单与隐私

| 数据 | 位置 | 是否上传 | 用途 | 保留 |
|---|---|---|---|---|
| 原图/成片 | iPhone | 否 | 本地编辑 | 用户删除/导出后清理 |
| 缩略图/风格卡 | iPhone | 否 | 展示 | 删风格即删 |
| 风格/编辑参数 | iPhone | 否 | 本地渲染 | 直到删除 |
| 购买权益 | iPhone/Apple | 仅 Apple | 权益校验 | 按 Apple 政策 |
| 诊断/分析 | iPhone + 可选境内服务 | 可选、无照片 | 稳定性/改进 | 90 天，聚合 |
| 客服消息 | 境内客服工具 | 用户主动 | 支持 | 30 天 |

### 6.1 本地数据删除

- 设置 → 隐私 → 删除全部本地数据；二次确认。
- 删除风格、缩略图、编辑记录、缓存；不可恢复。
- 不涉及账号注销；订阅需在 Apple ID 取消。
- 无需数据导出接口；用户可自行保存成片。

### 6.2 隐私文案

- “照片只在手机本地处理，不上传服务器。”
- “无需登录；风格与编辑记录只在这台手机。”
- “订阅由 Apple ID 管理；删除 App 不会取消订阅。”
- “诊断数据不含照片/文件名；可在设置关闭。”
- 避免“100% 安全”“绝不泄露”等绝对化表述。

## 7. 监控、告警与回滚

### 7.1 看板

- 崩溃自由、启动、OOM、形变/导出失败；
- 校准完成率、首次保存、保存前调整项数；
- 背景扭曲/肤色投诉；
- 付费墙/购买/恢复/退款；
- App 备案/审核状态（人工）。

### 7.2 告警阈值

| 指标 | 警告 | 严重（暂停放量） |
|---|---|---|
| 崩溃自由 | <99.3% | <99.0% |
| 导出失败 | >2% | >3% |
| 购买错误 | >1% | >2% |
| 背景/肤色投诉 | 1 例 | ≥3 例或媒体风险 |

### 7.3 回滚

| 问题 | 动作 |
|---|---|
| 形变背景扭曲 | 降低默认强度/关闭腿拉长；发版修复 |
| 肤色事故 | 关闭匀肤/降低磨皮；扩大评测 |
| 支付故障 | 检查商品/本地 JWS；恢复购买；联系 Apple |
| 隐私事件 | 停止相关请求；保全日志；法务；通知/整改 |
| App 审核问题 | 暂停发布；按审核意见修复/申诉 |

## 9. 冷启动与增长（中国）

### 9.1 定位文案

- 主标题：**像你本人审美的自然精修**
- 副标题：瘦脸瘦身不歪背景；照片只在手机里。
- 信任点：本地处理、无账号、自然默认、可关闭形变。
- 避免：“变美神器”“完美脸”“一周逆袭”“颜值打分”。

### 9.2 渠道

| 渠道 | 动作 | 注意 |
|---|---|---|
| 小红书 | 30 位种子用户；真实前后对比；教程/避坑 | 标注合作；不虚假效果；素材授权 |
| 抖音 | 15–30 秒“自然瘦脸/背景不歪”演示 | 不制造容貌焦虑 |
| 微信生态 | 公众号/视频号教程；客服企微 | 不诱导分享 |
| ASO | 个性化修图、人像精修、瘦脸、自然美颜、背景保护 | 不堆竞品词 |
| 应用商店 | 截图突出“自然/背景保护/本地” | 准确，不夸大 |

### 9.3 定价

- 仅月付 ¥29.9；前 3 张免费。
- 不做年付/买断/虚假折扣。
- 上线 60 天后根据留存/退款/转化决定是否加年付。
- 学生/创作者计划：先不做，避免复杂化。
