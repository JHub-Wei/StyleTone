## 4. 覆盖缺口

1. P1 账号/擦除/批量/多风格未排测试，v2.1 启动时补充。
2. App 备案依赖外部审核，测试门禁需预留 buffer。
3. 未成年人保护/内容安全需法务细化后追加用例。
4. 云擦除的生成式 AI 标识/审核不在 MVP 矩阵。
5. 全球版（Apple+邮箱）另立矩阵，不复用中国版。
