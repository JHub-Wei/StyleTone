# 07 · MVP 任务级 Backlog（v3.0 / 纯本地）

- 文档版本：v3.0
- 日期：2026-10-22
- 总量：**66 个任务 / 250 人日**，与 [开发计划](03-delivery-plan.md) 一致。
- 估算为理想人日（PD），含自测与代码评审，不含产品/设计工时。
- 负责人代号：iOS-A、iOS-B、IMG（图像）、QA、PD（产品/设计）。
- MVP 无账号/无后端/无擦除；账号与擦除在 v2.1。

> **阶段说明**：本文是 Phase C 的完整 66 个原子任务；Phase A 自用执行 23 个 WP 子集（**含配对/校准/风格学习**，不含订阅/商店/完整 onboarding），见 [任务分解](10-task-decomposition/README.md) 与 [自用优先路线](11-personal-first-roadmap.md)。

> 新增需求先进入 v2.1 池；MVP 只做 P0。P1 账号/擦除/批量/多风格/牙齿眼睛不在本 Backlog。

## 完成定义

- 代码/文档合并，CI 绿灯；
- 验收标准逐条通过；
- 有自动化测试或人工记录；
- 错误/离线/权限态处理；
- 无新增照片/参数上传路径；
- 性能在预算内；
- 简体中文与无障碍；
- 需求追踪矩阵更新。
