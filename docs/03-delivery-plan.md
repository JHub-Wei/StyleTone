### 1.2 与上一版（含账号）的差异

| 项目 | 含账号版 | 纯本地版 |

| 周期 | 28 周 | **24 周** |

| 擦除 | P1 云端 + 账号 | P1 不变；账号随擦除一起 v2.1 |

### 1.3 计划假设

- W1 启动用户研究、样本采集、App 备案/隐私政策。
- 外部 TestFlight Beta Review 提前 2 周提交。
- 不做擦除、账号、同步、批量、多风格、社区、牙齿/眼睛。
- 产品/设计稿在 W5 前完成 80%。
- 不接受“为赶 24 周砍掉背景保护/肤色测试”；宁可延期。
- 纯游客意味着没有远程账号后端，但 App 内购买/恢复仍通过 StoreKit/Apple。

## 4. 阶段与 Sprint（12 个双周）

### Sprint 0（W1–W2）：验证与合规前置

- 15 位目标用户深访；100+ 组授权人像配对；Concierge 10 人。
- S1 形变/背景：100 张，明显扭曲 <5%。
- S2 皮肤/肤色：Fitzpatrick I–VI，无过亮/偏灰。
- S3 风格/AB：3/5 组 + 6–8 次选择，盲测 ≥65% 或缩范围方案。
- S4 性能：30fps、6s 导出、90s 学习。
- S5 订阅/合规：StoreKit 月付、恢复、App 备案材料清单。
- **M0**：S1/S2 通过；S3 有结论；否则不全量开发。

### Sprint 1（W3–W4）：工程基础与设计

- 仓库/CI/签名/TestFlight；SPM 模块；设计系统；导航；错误/日志；本地配置。
- 欢迎/隐私/游客模式；示范素材框架；分析骨架。
- App 备案/隐私政策启动。

### Sprint 2（W5–W6）：端到端薄片

- PHPicker 单人像导入；分析；简单磨皮；一个瘦脸滑杆；导出。
- 自然默认；前后对比；基础编辑器。
- **M1**：真机跑通“选人像 → 形变/磨皮 → 导出”；无上传。

### Sprint 3（W7–W8）：人脸形变

- 瘦脸、下颌；多脸提示；五官保护；背景直线保护 v1。
- 网格/预览性能；撤销/重置；强度。
- 黄金图 v1。

### Sprint 4（W9–W10）：身材/腿

- 瘦手臂、瘦腰、瘦腿、拉长腿；遮挡/多人提示；背景保护 v2。
- 边缘延展/裁切策略；性能降级；内部盲测第一轮。

### Sprint 5（W11–W12）：皮肤、风格与质量门

- 磨皮、匀肤、点选去瑕疵；多肤色测试。
- 3/5/8 组校准；6–8 次 AB；风格卡/置信度；推荐力度。
- 影调/色彩/颗粒。
- **M2**：内部盲测 ≥60%；背景扭曲 <5%；性能 80%。

### Sprint 6（W13–W14）：编辑器完整化

- 四区工具；20 步撤销；对比手势。
- 场景提示（无人脸/多人/遮挡/低光）；失败回退。
- 自然档/标准档；背景保护开关。

### Sprint 7（W15–W16）：订阅、设置与 Alpha

- StoreKit 月付/恢复/离线宽限；付费墙/免费额度。
- 设置/隐私/诊断/帮助/删除本地数据。
- 性能/内存/热第一轮；内部 dogfood。
- **M3** 功能完整 Alpha。

### Sprint 8（W17–W18）：质量与 Beta 准备

- 设备矩阵；黄金图；隐私抓包；日志扫描。
- 无障碍/简中；崩溃/导出失败修复。
- 外部 TestFlight Beta Review 提交；100 人招募。

### Sprint 9（W19–W20）：Beta

- 外部 Beta 2 周；反馈；Top 缺陷修复。
- 背景/肤色/自然度专项；付费墙转化初测。
- **M4**：崩溃 ≥99%；外部盲测 ≥65%；无 P0/P1。

### Sprint 10（W21–W22）：合规与商店

- App 备案/隐私政策/SDK 清单；订阅审核。
- 商店截图/预览/关键词/描述；审核说明。
- 回滚演练；客服 FAQ；监控看板。
- **M5**：审核通过或仅剩可快速修复项。

### Sprint 11（W23–W24）：上线

- 分阶段发布（1% 起）；首日监控；热修窗口。
- 复盘；v2.1（账号/擦除）与 v2.2（批量/多风格/细节）立项评审。
- **M6** 上线。

## 5. 测试计划

### 5.1 设备矩阵

| 设备 | 用途 |
|---|---|
| iPhone 12 / 13 | 主流基线、性能 |
| iPhone 15 / 当前 Pro | 新系统、48MP、P3 |
| iPhone SE 3 | 小屏/内存压力 |
| 云真机 | 系统小版本/区域 |

系统：iOS 17 最新、当前-1、当前正式版。

### 5.2 人像样本

- 脸型：圆/方/长/心形/不对称；单/多人；遮挡。
- 身材：不同体型、服装、坐/站/走、手持物；不只测瘦模特。
- 肤色：Fitzpatrick I–VI，每类 ≥15 组。
- 背景：门框、地砖、栏杆、桌沿、文字、建筑、纯色墙、复杂图案。
- 光线：自然/室内暖光/逆光/夜景/闪光。
- 年龄：18–45；不主动收集未成年人样本。

### 5.3 质量指标

- 背景明显扭曲 <5%；投诉 <1%。
- 盲测偏好 ≥65%（个性化 vs 默认美颜）。
- 肤色无过亮/偏灰/偏白；纹理保留。
- 形变后仍可识别本人（人工盲测）。
- 预览 ≥30fps；12MP 导出 ≤6s；5 组学习 ≤90s。
- 隐私抓包无照片/参数上传。

### 5.4 测试类型

| 类型 | 频率 | 门禁 |
|---|---|---|
| 单元 | 每次 PR | 核心覆盖 ≥70% |
| 黄金图 | 每日 | 背景/肤色/边缘无回归 |
| UI | 每日 | 首次流程/付费墙/删除本地数据 |
| 性能 | 每周/发版 | 预算内；无 >10% 回归 |
| 隐私 | 每个 Beta | 无照片上传；无 PII 日志 |
| 设备 | 每个 Sprint | P0 设备全通 |
| 无障碍 | W18/W20/发版 | VoiceOver/字体/对比度 |
| 订阅 | 每个 Sprint | 月付/恢复/退款/离线 |
| Beta | W19–W20 | 100 人/2 周/无阻断 |

## 6. 发布标准

- 所有 P0 验收通过；无 P0/P1 缺陷。
- 外部盲测 ≥65%；背景扭曲 <5%；肤色无事故。
- 崩溃自由 ≥99.5%（Beta ≥99%）；导出失败 <1%。
- 5 组学习 ≤90s；预览 ≥30fps；12MP 导出 ≤6s。
- StoreKit 月付/恢复/退款路径通过。
- App 备案/隐私政策/内购审核完成。
- 100 名外部 Beta、2 周；Top 5 问题关闭。
- 回滚/热修/客服 Runbook 就绪。

**不可上线**：背景扭曲明显、肤色事故、照片被上传、订阅无法恢复、App 备案未完成。

## 8. 计划风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 形变背景扭曲 | 核心体验/口碑 | W2 Spike；背景保护；限幅；不达标缩范围 |
