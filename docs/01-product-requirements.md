## 1. 背景与问题定义

### 1.1 用户真正要完成的任务

目标用户拍完人像后，通常不是“缺一个滤镜”，而是要在发小红书/朋友圈/抖音前完成一套重复的精修：

1. **脸型**：瘦脸、下颌线、颧骨/太阳穴比例。
2. **身材**：瘦手臂、瘦腰、瘦腿、拉长腿。
3. **皮肤**：磨皮、匀肤、去痘/去瑕疵、黑眼圈。
4. **影调**：曝光、对比、色温、肤色、颗粒。
5. **背景**：避免门框/地砖/桌沿被拉歪，避免“P图痕迹”。
6. **速度与一致性**：每次都要重新调，修出来有时自然、有时假。

现有工具要么模板感强（“网红脸”），要么操作复杂（Lightroom/专业修图），要么需要把照片上传云端。用户想要的是：**自然、快、像自己审美的精修，而且不被别人看出“P过”**。

### 1.2 产品机会

用户过去的“原图 + 满意成片”以及她在 App 内的调整，都是个人偏好数据。App 可以学习：

- 她偏好的肤色、磨皮强度、脸型/身材力度、影调；
- 她在不同场景下的保守/大胆程度；
- 她对“自然感”的边界。

然后把这些偏好变成默认值，减少每次重复调参。**风格学习是差异化能力，但核心交付是“好用的人像精修工具”**，不是“调色滤镜”。

### 1.3 第一原则

**学审美，不做换脸；做精修，不做变形怪。**

- 做：肤色、磨皮、去瑕疵、脸型/身材轮廓、腿长、影调、背景保护。
- 不做：换脸、身份替换、生成不存在的五官、瘦到背景扭曲、公开社区、颜值评分、皮肤诊断、美白/漂白。

## 2. 目标用户

### 2.1 核心人群

| 项目 | 描述 |
|---|---|
| 年龄 | 18–30 岁，女性为主 |
| 城市 | 一二线及新一线，移动互联网重度用户 |
| 行为 | 每周发 1–3 次人像/生活照；常用美图秀秀、醒图、BeautyPlus、Ulike |
| 设备 | iPhone 12 及以上为主，iOS 17+ |
| 付费 | 对“省时 + 自然 + 不撞风格”有付费意愿，但对订阅疲劳敏感 |
| 敏感点 | 怕假面、怕背景歪、怕被说“P得不像”；重视隐私与“不被上传” |

### 2.2 典型用户

**小雅，24 岁，上海，市场专员**
- 每周发 2–3 条小红书，照片以咖啡店、旅行、自拍为主。
- 习惯用醒图/美图：先瘦脸，再磨皮，再调色；每次 5–10 分钟。
- 痛点：不同光线下的肤色不一致；瘦脸后背景门框弯；模板感太重。
- 想要：一键接近自己平时的修法，但能微调；不要“网红脸”。

**安安，27 岁，杭州，旅行博主**
- 一次旅行拍 300–800 张，回程集中修 20–30 张人像。
- 痛点：每张重复调；风景照里的路人要擦除；不同设备肤色不一致。
- 想要：批量（v2.1）、自然肤色、背景保护；擦除可以付费。

### 2.3 非目标用户

- 专业商业修图师：需要图层、蒙版、印刷级校色。
- 想换脸、生成虚构形象、做二次元/幻想风格的用户。
- 想在 App 内建立公开作品社区/粉丝关系的用户。
- 需要医疗护肤诊断、颜值评分、肤色漂白的用户。

### 2.4 Jobs to Be Done

> **功能**：当我拍完一张人像，我想在几分钟内完成瘦脸、瘦身、磨皮、调色，而且背景不歪。
>
> **情绪**：我想看起来像“更好的自己”，不是“另一个人”；我不想被看出用了很重的模板。
>
> **社交**：我想保持自己主页的审美一致性，发出去不被朋友说“P得太假”。

## 3. 市场与竞争

| 产品 | 强项 | 我们的差异 |
|---|---|---|
| 美图秀秀 | 功能全、模板多、认知强 | 模板感/广告/功能臃肿；我们做“个人审美 + 自然 + 本地” |
| 醒图 | 年轻女性审美、滤镜/模板强 | 我们学她自己的修法，而不是套模板 |
| BeautyPlus/Ulike | 人像美颜成熟 | 我们强调背景保护、可控形变、隐私 |
| Retouch | 去路人强 | 我们做人像精修 + 个性化，擦除后置 |
| Snapseed/Lightroom | 手动能力强 | 普通用户学习成本高；我们降低门槛 |
| 苹果照片 | 零门槛 | 通用增强，不学个人偏好 |

**竞争判断**：这是一个拥挤市场，不能靠“功能更多”赢。能赢的点只有三个：

1. **更像她**：默认值来自她自己的成片/选择，而不是统一模板。
2. **更自然**：背景保护、形变限幅、保留纹理，减少“P图痕迹”。
3. **更安心**：照片本地处理、无账号、可删除。

## 4. 定位、原则与伦理

### 4.1 定位

> **自然、可控、像你本人审美的 AI 人像精修。**
>
> 不用学复杂软件，也不用套别人的模板；用你自己的照片和选择，校准出你的精修手感。

### 4.2 产品原则

1. **自然优先**：默认强度保守；任何形变都可降低/关闭；保留皮肤纹理。
2. **背景保护**：形变时优先保持直线、边缘、文字、建筑结构；宁可少瘦，不可拉歪。
3. **用户可控**：前后对比、强度、手动工具、撤销/重做、重置。
4. **本地优先**：MVP 照片/参数/编辑全部本地，不上传、无账号；云擦除 v2.1 单独授权。
5. **不制造焦虑**：不做颜值评分、皮肤诊断、美白/漂白、胖瘦羞辱、夸张 before/after。
6. **像她本人**：不做换脸/身份替换；形变只改轮廓，不重绘五官。
7. **轻量启动**：3 组即可试用；可跳过校准用自然默认；无需登录。
8. **可解释**：风格卡说明学到了什么；置信度低时明确提示。

### 4.3 伦理与安全边界

- 默认不自动应用高强度形变；首次使用展示“自然/标准”两档，默认自然。
- 不提供“变美前后评分”“脸型打分”“皮肤年龄”等伪科学指标。
- 不提供肤色美白/漂白；肤色调整仅匹配个人风格，限幅。
- 不主动面向未成年人营销；隐私政策与年龄分级按中国法律意见执行。
- 不做公开社区；擦除功能上线前建立违法/色情/未成年人内容审核与举报机制。
- 不把用户照片用于训练；MVP 无账号；v2.1 账号同步只含参数与偏好。

## 5. 关键假设与验证

| 假设 | 验证 | 通过标准 |
|---|---|---|
| H1：用户愿意提供 3–5 组原图/成片 | 15 位深访 + 相册观察 | ≥70% 能当场找到 3 组 |
| H2：个性化默认值优于通用美颜 | 30 人盲测 A/B | ≥65% 偏好个性化结果 |
| H3：形变背景保护可接受 | 100 张真实人像评测 | 明显背景扭曲 <5%，投诉 <1% |
| H4：3 分钟校准不伤害激活 | TestFlight/内测 | 校准完成率 ≥55% |
| H5：用户愿意为“自然 + 省时”付费 | 假门/预约/内测 | 付费墙转化 ≥15% |
| H6：纯游客模式不降低首次保存 | 内测漏斗 | 安装 → 首存 ≥35%，不因无账号流失 |

**Concierge 测试**：开发前用半自动流程为 30 位目标用户各修 10 张，观察是否愿意直接发布、是否觉得“像自己”、是否愿意付费。H2/H3 不通过则暂停全量开发。

## 6. 目标与指标

### 6.1 北极星指标

**每周成功保存的个性化人像成片数（Weekly Saved Portrait Edits）**。

### 6.2 漏斗目标（上线首 90 天假设）

| 阶段 | 指标 | 目标 |
|---|---|---|
| 激活 | 安装 → 首次保存 | ≥35%，中位 ≤10 分钟 |
| 校准 | 开始校准 → 完成 3 组 | ≥55% |
| 质量 | 保存前手动调整 ≤2 项 | ≥50% |
| 质量 | 盲测偏好（vs 默认美颜） | ≥65% |
| 留存 | D7 / D30 | ≥25% / ≥12% |
| 商业 | 付费墙 → 订阅 | ≥15%（目标 20%） |
| 稳定 | 崩溃自由用户率 | ≥99.5% |
| 口碑 | 背景形变/“太假”投诉 | <1% |

### 6.3 反指标

- 用户把形变强度调到 0 的比例（说明默认过强）。
- 保存后 10 分钟内重编同一张的比例。
- 背景扭曲/肤色事故投诉。
- 校准中途放弃率。
- 首次流程中途放弃率。
- 订阅退款率（目标 <3%）。

## 7. 范围与版本

### 7.1 MVP（中国首发，24 周）

- iPhone、iOS 17+，**仅简体中文**。
- **纯游客、纯本地**：不登录、不建账号、不上传照片、不做同步。
- 风格校准：3 组试用 / 5 组标准 / 8 组稳定；可跳过用“自然默认”。
- 人像工具：
  - 瘦脸、下颌；
  - 瘦手臂、瘦腰；
  - 瘦腿、拉长腿；
  - 磨皮、匀肤、点选去瑕疵；
  - 曝光、对比、色温、饱和度、颗粒；
  - 背景保护开关。
- 风格卡、置信度、推荐力度、前后对比、撤销/重做、重置。
- 全分辨率导出到相册/分享；默认去 GPS。
- 前 3 张免费；月付 ¥29.9 解锁无限导出。
- 设置、隐私、诊断开关、帮助。
- 离线核心可用。

### 7.2 v2.1（上线后 8–12 周，按数据决定）

- **账号 + 微信/手机号/Apple 登录 + 参数同步**：为云擦除与换机服务。
- **云端物体/风景擦除**：单张授权、登录、额度、自动删除、内容审核。

### 7.3 v2.2（更后）

- 批量编辑（2–20 张）。
- 多风格（人像/旅行/日常）。
- 黑眼圈、牙齿/眼睛轻微提亮。
- 全球版（Apple + 邮箱，无微信）。
- 摄影师/博主授权风格包（需版权与审核）。
- iPad / 分享扩展 / 快捷指令。

### 7.4 明确不做

- 换脸、身份替换、生成虚构五官/身体。
- 公开社区、评论、作品广场。
- 颜值评分、皮肤诊断、肤色美白/漂白。
- 专业图层/蒙版/印刷级校色。
- Android/Web 编辑器（首发）。
- 视频修图。
- 云端人像重绘（擦除是局部修复，不是重绘整个人）。

## 8. 核心流程

### 8.1 首次进入（纯游客）

1. 欢迎页：一句话价值 + “照片只在手机本地处理” + “无需登录”。
2. 选择路径：
   - **快速校准**：3 组原图/成片 + 6–8 次 A/B 选择。
   - **自然默认**：跳过校准，直接用人像默认风格。
3. 示范：内置授权样片展示“自然/标准”两档，避免用户不知道效果。
4. 进入首页：修一张照片 / 继续完善风格。

### 8.2 快速校准（目标 ≤4 分钟）

1. 说明：选“你满意的成片”，再选同场景原图；人像、光线接近；不要加字/贴纸。
2. 逐组选择：原图/成片双槽；自动检查人脸、配准、分辨率、结构改动。
3. 3 组后可选：
   - 直接生成“试用风格”；
   - 再做 6–8 次 A/B 选择（肤色/磨皮/脸型/身材/影调/自然度）；
   - 补到 5 组/8 组提升置信度。
4. 校准进度：检查 → 对齐 → 肤色 → 磨皮 → 脸型/身材 → 影调 → 风格卡；可取消、可暂停。
5. 风格卡：标签、置信度、推荐力度；用 1 组自己的样本展示前后对比。
6. 首次修图。

**无配对用户**：可只做 6–8 次 A/B 选择，生成“偏好风格”，不声称是“从你的成片学习”。

### 8.3 编辑流程

1. 从相册选 1 张人像（PHPicker，无需完整相册权限）。
2. 本地分析人脸/人体/背景；应用风格默认值。
3. 首屏展示“推荐力度”，用户可：
   - 长按看原图；分屏拖动对比；双指缩放。
   - 总强度 0–150%（默认 100%，自然档约 70%）。
   - 脸型：瘦脸、下颌；身材：手臂、腰、腿、拉长；皮肤：磨皮、匀肤、去瑕疵；影调：曝光、对比、色温、饱和、颗粒。
   - 背景保护开关；重置；撤销/重做 ≥20 步。
4. 点选去瑕疵：放大 → 点痘/斑/杂物（小范围）→ 本地修复；可撤销。
5. 导出：HEIC/JPEG；默认去 GPS；保存/分享；失败可重试。

### 8.4 账号流程（v2.1，MVP 不做）

- MVP 不展示登录入口；设置内仅说明“本地模式，数据只在这台手机”。
- v2.1 引入账号后：微信/手机号/Apple；登录后同步参数；删除账号；订阅不自动取消。
- v2.1 的账号只同步参数/偏好，不上传照片；云擦除另做单张授权。

### 8.5 付费墙

- 触发：第 4 次成功导出前；也可从首页主动进入。
- 权益：无限导出；后续批量/多风格/云擦除另计。
- 价格：**仅月付 ¥29.9/月**；若 App Store 无此价格点，映射最近可用价（如 ¥30）。年付/买断等数据验证后再评估。
- 必须：价格、周期、自动续订、取消方式、恢复购买、隐私政策、服务条款。
- 免费额度用尽后仍可预览/调整；不做水印，不能导出可保存成片。
- 保存到相册或系统分享成功均计一次；失败/取消不计。

## 9. 功能需求

优先级：P0 首发；P1 v2.1；P2 以后。

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| FR-01 | 游客模式与隐私说明 | P0 | 无需登录即可完成校准/编辑/导出；首次 30 秒内说明照片本地处理 |
| FR-02 | 示范体验 | P0 | 内置授权样片展示自然/标准两档；离线可用；不计导出 |

| FR-04 | 配对质量检查 | P0 | 人脸/配准/分辨率/结构改动分级；红色拒绝并说明原因 |

| FR-18 | 可选登录（v2.1） | P1 | 微信/手机号/Apple；v2.1 与账号/云擦除一起上线 |

## 11. 交互与视觉

- **暗房感**：深色背景、照片周围 18% 中性灰；避免品牌色干扰判断。
- **工具分区**：脸型 / 身材 / 皮肤 / 影调，四个 Tab；每区 ≤5 个滑杆。
- **自然档**：默认 70% 强度；首次展示“自然/标准”对比，不默认“网红”。
- **背景保护**：开启时在变形区域显示细线提示；关闭时二次确认。
- **对比手势**：长按看原图、分屏拖动、双指缩放；不改变导出。
- **文案**：用“更接近你平时的修法”“保留背景直线”，避免“变美/完美/女神”。
- **删除/退出**：破坏性操作二次确认，默认焦点“取消”。
