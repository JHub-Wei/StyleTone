# 私调 StyleTone · 个性化人像精修 iPhone App

> 暂定名，上线前需完成商标与名称检索。项目代号：StyleTone。
>
> **一句话产品**：从用户喜欢的原图/成片与少量选择中，学会她的肤色、磨皮、脸型/身材力度与影调，用可控、自然的人像工具完成 P 图。
>
> **核心信任承诺**：MVP 照片仅在手机本地处理，不登录、不上传；不做换脸/身份替换；形变默认保守、强度可控；风格可解释、可调节、可删除。
>
> **开发目的修订（2026-10-24）**：先自用 → 朋友 TestFlight → 再 App Store 月订阅。**Phase A 自用版 16–18 周，核心“配对学习→生成成片”已闭环**；商业化总计约 26–31 周。详见 [自用优先路线](docs/11-personal-first-roadmap.md)。

## 3. 范围（Phase A 先做，Phase C 再加商业层）

### Phase A 自用版

- 纯本地、无登录、无上传。
- **核心闭环：导入 3–5 组原图/成片 → 学习风格 → 导入新原图 → 生成成片 → 导出。**
- 单张人像导入/导出；瘦脸/下颌、瘦手臂/腰、瘦腿/拉长。
- 磨皮/匀肤、点选去瑕疵、影调/色彩/颗粒、背景保护。
- 自然档、前后对比、20 步撤销；“我的默认”可保存。
- 3 组试用 / 5 组推荐 / 8 组稳定 + 6–8 次 A/B；可跳过用自然默认。
- 最小设置：删除本地数据、版本/隐私说明。
- **无订阅、无付费墙、无账号、无云、无擦除、无批量、无多风格、无完整 onboarding。**

### Phase B 朋友 TestFlight

- 风格卡、简单引导/示范、空状态。
- TestFlight 10–30 位朋友；仍免费、无账号。
- 收集自然度/背景/肤色/持续使用反馈；不上传照片。
- 不订阅、不上 App Store、不备案。

### Phase C App Store 商业化

- 月付 ¥29.9；前 3 张免费；StoreKit 2 恢复购买。
- 正式 onboarding/设置/隐私/诊断、无障碍、多设备 QA。
- App 备案、隐私政策、商店素材、审核、分阶段发布。
- 仍不做账号/微信/云擦除/批量/多风格。

**v2.1（商业化后 8–12 周）**：账号 + 微信/手机号/Apple + 参数同步 + 云端擦除。
**v2.2（更后）**：批量、多风格、牙齿/眼睛/黑眼圈、全球版。

## 4. 关键指标

| 指标 | 目标 |
|---|---|
| 安装 → 首次保存 | 中位数 ≤10 分钟 |
| 校准完成率 | ≥55% |

## 5. 下一步（按 Phase A 执行）

1. **W1–W2 可行性验证**：背景保护形变、多肤色磨皮、3 组配对学习、端侧性能；不达标不进入全量开发。
2. **Phase A 只做 23 个 WP**：WP-00~11、12~17、19、21、23~25；核心闭环必须先跑通，不把配对学习后置。
3. **自用 4 周**：记录每周使用次数、单张耗时、风格相似度、背景/肤色问题；保存 before/after 样本（自己授权）。
4. **Phase B 朋友 TestFlight**：加风格卡/引导/反馈；10–30 人、4 周；验证 D7/自然度/付费意愿。
5. **Phase C 商业化**：只有 Phase B 达标才做 StoreKit 月付、App 备案、商店素材、正式 QA。

**不要**在 Phase A/B 提前做订阅、付费墙、App Store 素材、App 备案、完整多设备矩阵；这些是 Phase C 的成本。

## 6. 重要说明

- 价格、周期、转化率、性能目标均为规划假设，需真实数据校准。
- 法规部分为产品工程清单，**不构成法律意见**；中国上线前须由执业律师复核。
- 18+ 是定位与营销边界，不等于技术上绝对阻止未成年人下载；年龄提示/隐私政策按法律意见执行。
- “学习风格”在 UI 中描述为“根据原图/成片和选择校准参数”，避免暗示训练大模型或复制某位博主。
- 形变与美颜涉及身体形象，默认自然、可关闭、禁止“颜值评分/皮肤诊断/美白”。
